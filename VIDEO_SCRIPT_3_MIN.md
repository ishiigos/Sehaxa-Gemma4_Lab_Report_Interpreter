# Sehaxa 3-Minute Hackathon Video Script

## 0:00–0:20 — Hook
Every day, millions of people receive lab reports filled with numbers they do not understand. Hemoglobin, TSH, HbA1c, Vitamin D — these values can affect real health conversations, but for many patients, the report feels like a foreign language.

## 0:20–0:45 — Problem
In India, this gap is even larger. Many users face language barriers, limited doctor consultation time, and low access to personalized explanations. Searching online often creates more fear than clarity.

## 0:45–1:05 — Introduce Sehaxa
This is Sehaxa: an AI-powered lab report interpreter built with Gemma 4. Sehaxa helps users upload a lab report photo, extract common values, and understand them in simple English and Hindi.

## 1:05–1:55 — Demo
Here is a sample report image. The user uploads the report, and Sehaxa extracts values like hemoglobin, WBC count, TSH, Vitamin D, and Vitamin B12 using OCR.

The user can correct any extracted value manually, because health data needs care. Then Sehaxa structures the report, compares values with reference ranges, and sends the structured data to Gemma 4.

The output explains what each test means, whether the value is low, normal, or high, possible non-diagnostic reasons, and what the user should ask their doctor.

## 1:55–2:25 — Gemma 4 Technical Explanation
Gemma 4 powers the explanation layer. It reasons over structured lab data and produces safe, bilingual, patient-friendly insights. The prompt is constrained so the system does not diagnose, prescribe, or create panic. Instead, it focuses on health literacy and doctor-facing questions.

## 2:25–2:45 — Impact
Sehaxa is designed for India: multilingual, accessible, and privacy-aware. The goal is not to replace doctors. The goal is to help patients understand their own health data before they walk into a clinic.

## 2:45–3:00 — Closing
With Gemma 4, Sehaxa turns confusing lab reports into clarity — helping people move from anxiety to informed conversations.
